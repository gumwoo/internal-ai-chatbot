# 구현 참고 02. 전체 대화 실행 의사코드

재구성 전의 전체 실행 의사코드를 보존했습니다. 하나의 모듈에 모두 넣으라는 구현 지시가 아닙니다. 수락·저장·만료 처리는 MOD-01, 모델·도구 반복은 MOD-02의 책임으로 분리합니다. 현재 계약은 [협력 구조](../architecture/05-collaboration.md)를 따릅니다.

```text
현재 사용자와 대화 소유권 확인
활성 실행 확보, 사용자 메시지 저장
검증된 대화 상태와 이번 실행의 상대 날짜 기준 준비
제한 안에서 반복:
    모델 호출
    도구 요청이면:
        순서대로 허용 여부와 인자 검증
        도구 실행, 결과와 ID 기록
        모델 문맥에 해당 도구 결과 추가
    최종 응답이면:
        응답 스키마, 교육 참조, 인용 ID 확인
        사용자용 데이터 구성 후 완료 저장
        종료
한도·시간·최종 장애면 실패 저장 후 오류 응답
```
