## 테스트 수준

- 업무 정책: 날짜·ACL·판본·준비/확인 상태·멱등성은 결정적 단위 테스트.
- 모듈 계약: 가짜 모델·clock·저장소로 실패와 소유권을 검증.
- DB 통합: 수락/완료·게시·확인의 원자성·동시성, 실제 pgvector 필터를 검증.
- 실제 모델 smoke: 도구 선택·최종 형식·원문 인용을 적은 시나리오로 확인. 매번 전체 테스트를 유료 호출로 돌리지 않는다.
- 화면 E2E: 대화→출처/PDF, 준비→확인→동일 결과, 권한 만료/새로고침을 검증.

## 평가

총150문항 목표와 dev50/holdout100 분리는 [비교 프로토콜](13-retrieval-comparison.md)을 따른다. 문항 수를 늘리는 것보다 원문 gold·예외·시점·권한 검수를 먼저 한다. 통합 검색 품질과 Agent end-to-end 품질은 구분해서 측정한다. 보고서에서 표본 수·실패·fallback·미확인 비용을 숨기지 않는다.
