# 사용자 제작 PDF 100개 구성

이 파일은 **초기 제목·식별자 계획**이다. PDF100개는 수령했으며 실물 파일명·제목의 기준은 [수령 목록](02-received-register.md)이다. 아래 제목은 실물과19건(띄어쓰기 차이 포함) 다르므로 표시용 manifest에 그대로 복사하지 않는다. 규정 본문·실제 정책·권한 배정은 이 계획으로 확정하지 않고 [메타데이터 계약](01-metadata-contract.md)에 따라 검수한다.

100개는 물리 PDF 수다. 현행91개+구버전9개이며 논리 문서는91종이다. 구버전은 현행과 같은 document_key를 쓰되 서로 다른 source_file_id·업무 version·유효기간을 가진다. 단일 판본 문서의 제목에는 현행 표기를 생략했다.
