# 사내 업무 도우미 화면 시안

기존 교육 화면의 배치·색감·서체를 유지하고 통합 업무지원의 세 흐름을 추가한 정적 HTML/CSS/JS 시안이다. 실제 서비스 코드는 작성하지 않았다.

## 실행

워크스페이스 루트를 정적 서버의 루트로 열어야 PDF 상대 링크도 동작한다. 현재 미리보기는 http://127.0.0.1:8787/prototypes/work-assistant/ 이다. 서버가 종료되면 `C:\LLM-API`에서 `python -m http.server 8787 --bind 127.0.0.1 --directory C:\LLM-API`로 다시 열 수 있다. 이는 파일 제공용 정적 서버이며 업무 API가 아니다.

## 눌러볼 흐름

첫 화면 하나에서 시작한다. 검토용 상단 탭과 상태 선택창은 제거했다. 추천 질문을 누르거나 질문을 직접 입력하면 같은 대화 화면에서 흐름이 이어진다. 새 대화로 첫 화면에 돌아갈 수 있다.

- **외부교육비 추천 질문**: 지원 한도 → 인용 번호/문서 행 → 원문 번호·판본·PDF1쪽 링크.
- **9월 출장 추천 질문**: 종전 숙박비 → 현재 기준과 비교 → 두 원문 확인.
- **VPN 추천 질문**: 입력값 수정 → 요청 내용 확인 → 확인/수정/취소 → 가상 DEMO-IT 접수번호.
- **다음 주 교육 일정 질문**: 기존 일정·상세·불참 규정 흐름 유지. 예정2건은 첫 구현 명세의 fixture와 맞췄다.

예외 상태의 요구사항은 설계 문서에 유지한다. 사용자가 상태를 선택하는 메뉴로 노출하지 않는다.

검토 반영: 교육비의9월 후속 질문은 같은 대화의 교육비 문맥에서 날짜 확인으로 이어진다. 출장 예시는 출발일·수도권을 질문에 명시하고 답변에 복귀일을 임의 추가하지 않는다. 입력 경계 대비를 보정했다. 서버의 수정 재준비 API는 명세만 추가했으며 이 시안은 계속 로컬 고정 응답이다.

## 데이터와 한계

PDF는 사용자가 제공한 가온웍스 가상 회사 자료다. 응답·인용은 사람이 원문을 확인해 넣은 고정 예시이며 검색 결과가 아니다. 자유 질문은 키워드 분기로 예시 응답을 선택한다. 교육·티켓 프로필·접수번호는 가상 데이터다. 날짜는 시나리오 재현용으로 고정했다.

입력 내용은 외부 전송하지 않는다. 대화·요청은 이 탭 메모리에만 있고 새로고침하면 초기화된다. 실제 AI·인증·ACL 집행·DB·업무 API·티켓 생성은 없다. 실제 메타데이터/ACL 게시와 자동 검색은 다음 구현 단계다. 시안의 만료·중복 클릭 처리는 화면 검토용이며 운영 트랜잭션 검증을 대체하지 않는다.

PC는 대화 목록·중앙 대화·선택적 상세, 모바일은 메뉴·전체 너비 상세를 사용한다. [화면 사용 순서](../../docs/ui/02-prototype-walkthrough.md), [PDF 반영 설계](../../docs/corpus/03-received-pdf-adjustments.md), [MOD-08](../../docs/modules/MOD-08-chat-ui.md)이 연결 문서다.

[테스트 실행 방법](tests/README.md)과 [브라우저 스크립트](tests/browser-flows.cjs)를 저장했다. 날짜 재질문, 사용자 미진술 필드, 폼 보존/메시지 바인딩, draft→pending, 수정 취소/교체, 만료, escape, 모바일 포커스 및 검증 전용 예외 fixture를 확인한다. 서버 경쟁/인증이나 실제 검색 품질은 테스트하지 않는다.
