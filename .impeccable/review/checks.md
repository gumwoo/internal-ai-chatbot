# 화면 시안 검증 기록

대상: `prototypes/education-agent/`. 화면 검토용 로컬 시안이며 서버·모델·DB 통합 검증을 뜻하지 않는다.

## 확인한 항목

- `node --check prototypes/education-agent/app.js` 통과.
- 대표 화면 전환: 첫 화면·일정 조회·규정과 출처.
- 모바일 예시 질문 전송과 샘플 답변 표시.
- 교육 상세 열기·닫기, 닫은 뒤 원래 교육 버튼으로 포커스 복귀.
- 규정 인용 구간 보기, 모바일에서 전체 너비 보기로 전환.
- 조회 실패 상태·재시도 뒤 샘플 일정 표시.
- 모바일 대화 목록 열기·Escape로 닫기·열기 버튼으로 포커스 복귀.
- 390px·1280px에서 문서 가로 넘침 없음.
- 기존·신규 사용자 문서의 로컬 링크 검증 통과.

브라우저 크기 변경 직후 반환된 이전 크기의 캡처를 감지해 교체했다. 교체 후 실제 파일 크기를 확인하고 전체 화면 검토를 다시 받았다.

## 시안 검토

별도 검토자의 최종 판정: `ship`. 근거: [reviewer-result.md](reviewer-result.md). 코드 주도 시안이므로 승인된 이미지 시안과의 픽셀 일치 평가는 수행하지 않았다.

## 자동 탐지 기록

탐지기를 한 번 실행했다. 작은 기능성 글자·보조 안내 글자를 11px 이상으로 조정하고 모바일의 키보드 단축키 안내를 숨겼다. 상단 시안 탭의 하단 구분선 경고는 화면 검토에서 의도한 정렬로 판정했다. 수정 뒤 자동 탐지 재실행은 하지 않았고, 최종 코드와 캡처를 별도 검토자에게 전달했다.

## 한계

모든 데이터·처리 내역은 샘플이다. 자유 질문의 정확성·대화 영속화·인증·실제 도구 실패 복구·IME 전체 조합·스크린리더 사용성은 서비스 구현에서 검증해야 한다. 실제 LLM/RAG 또는 API 테스트가 통과했다는 의미가 아니다.
