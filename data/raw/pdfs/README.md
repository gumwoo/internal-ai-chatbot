# 사용자 PDF 입력 폴더

사용자가 제공한 가온웍스 가상 회사 PDF100개/248쪽을 수령했다. 현행91개·종전9개, 논리문서91종이다. 원본은 변경하지 않는다. 수령과 운영 게시 완료는 별개다.

- [실제 수령 파일·관찰 메타데이터](../../../docs/corpus/02-received-register.md).
- [초기 제목/ID 계획](../../../docs/corpus/00-document-inventory.md)은 실물 제목과 구분한다.
- [판본·시행일·권한·원문 추적 계약](../../../docs/corpus/01-metadata-contract.md).
- 수령한 `HR-001_문서명.pdf`/`ED-030_문서명.pdf` 형식을 그대로 보존한다. PDF-번호·DOC-논리키·GW-원래번호를 향후 검수된 `data/raw/document-manifest.json`에 매핑한다.
- 현행91개+구버전9개다. 구버전은 별도 파일로 보존하며 현행을 덮어쓰지 않는다.
- 파일 업로드/복사만으로 게시되는 구조가 아니다. manifest 검수·파싱 검수·snapshot 게시를 거친다.
- PDF의 사내 규정은 가상 데이터로 제작한다. 가상 조직/권한/시행일은 작성자가 결정하며 개발자가 임의 추정하지 않는다.

원본 파일은 이후에도 임의 수정하지 않고 새 판본으로 추가한다. 현재는 수집 명령이나 백엔드가 구현되지 않은 설계 단계다.
